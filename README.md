## How we vet

Every submission gets the same checks before it appears here — no account or purchase required, so you can repeat them yourself:

- **The product must run.** A pricing page is not a product; we look for the app, repo, or bot actually working behind it.
- **Every CTA must lead somewhere real.** "Launch", "Choose plan" and "Docs" buttons that all point at an in-page anchor mean there is nothing behind them.
- **Structured-data ratings must exist somewhere.** An `aggregateRating` on a site with no review mechanism is fabricated, especially when sister sites show the same score.
- **The paper trail must agree.** Wayback history, whois dates, and linked social accounts have to tell the same story the landing page tells.

The full checklist is in [CONTRIBUTING.md](CONTRIBUTING.md). Open-source submissions additionally get the scaffold-repo checks described there.
